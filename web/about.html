Límites

Lo que el modelo no puede decir.

  • Datos de ejemplo

    Telco Customer Churn es un dataset de IBM sobre una empresa ficticia. Sirve para aprender, no describe un mercado real.

  • Relaciones, no causas

    El modelo encuentra patrones. Que un factor pese mucho no prueba que cause el abandono.

  • Umbrales provisionales

    Bajo, medio y alto se cortan en 30% y 60%. Se ajustan junto con el equipo de Modelos.

  • Modelo provisional

    Mientras llega el modelo del equipo de Modelos, la API usa un modelo de prueba.
